Supabase Lite conformance

The same supabase-js calls, sent to real Supabase (Postgres) and to Supabase Lite (SQLite). Every difference is classified by how much it hurts an app.

Community project. Not affiliated with or endorsed by Supabase. This page reports what was measured, nothing more.

Declared gaps (S4) are acceptable for a lite version. Silent wrong data (S1) is what hurts users, so it is ranked first. A loud bug is an error on a feature the target does not say is unsupported.

Several cases can fail for the same reason, so failing cases are grouped by root cause. Attribution was made by reading the pinned Lite source; each group is ranked by its worst verdict.
